# Ribbon

お気に入りの場所と、小さなアクションをひとつに。Chrome標準ブックマークとは独立した、個人用ブックマーク／ブックマークレット管理拡張です。

## インストール（ビルド不要）

1. Chrome 138以降で `chrome://extensions` を開きます。
2. 右上の **デベロッパーモード** をオンにします。
3. **パッケージ化されていない拡張機能を読み込む** を選び、このフォルダ内の **dist** フォルダを指定します。
   - ZIP版の場合は先に展開し、`manifest.json` が直下にあるフォルダを選んでください。
4. Chromeの拡張機能メニューからRibbonをツールバーに固定します。
5. アイコン → **ワークスペースを開く** で管理画面を開きます。

初回は空のワークスペースです。「最初のブックマークを追加」から登録するか、「サンプルからはじめる」で編集可能なサンプルを追加してください。

**読み込んだフォルダは移動・削除しないでください。** 更新時は同じフォルダの内容を更新し、Chromeの拡張一覧でRibbonの再読み込みを押します。アンインストールすると登録データが消えるため、先にバックアップしてください。

## 使い方

### ブックマークをまとめる

- 「追加する」で名前・URL・メモ・検索キーワード・アイコン文字／絵文字・グループを登録します。
- URLとJavaScriptを同じグループに置けます。「ブックマーク」「アクション」フィルターで絞り込めます。
- カードの星でお気に入りを切り替え、鉛筆で編集します。
- 拡張ポップアップの「このページを保存」で、閲覧中ページのタイトルとURLを取り込めます。
- アイコンはブックマークのサイトのfaviconを既定で表示します(ChromeのローカルAPIのみ使用、外部サービスへの取得リクエストは送信しません)。文字・絵文字を設定するとそちらが優先されます。

### まとめページをデザインする

- **ページをデザイン** を押すと、グループ見出しとカードをドラッグして配置できます。
- カードを他グループ／左サイドバーへドロップするとグループを移動します。
- グループの編集から、名前・説明・色・アイコン・標準／ワイド幅・カード／リスト表示を変更できます。
- ドラッグを使わず、グループの「前へ／次へ」やカードの移動先選択・上矢印でも整理できます。
- ページ設定ではタイトル・サブタイトル・カバー3種類・2〜4列・余白を設定できます。狭い画面では列数を自動調整します。
- グループを削除しても、中の項目は「未分類」に残ります。

### テーマ

設定 → テーマで6種類の内蔵テーマをプレビューできます。「テーマを適用」で全画面へ反映します。

背景・サイドバー・カード・文字・アクセント・境界線を変更して、名前付きカスタムテーマとして保存できます。既存のカスタムテーマを選んで変更すると上書き、内蔵テーマから変更すると新規作成します。配色のコントラストも表示します。

### キーボード

- **Ctrl+Shift+Y**：拡張の検索ポップアップを開く（MacではCommand+Shift+Y）。他の機能との競合時はChrome設定で変更してください。
- 管理画面の **Ctrl+K / Command+K**：検索へフォーカス。
- 検索欄の **↑ / ↓ → Enter**：結果を選んで開く／実行。
- **Esc**：編集ダイアログまたはポップアップを閉じる。
- 設定 → キーで **30個の直接実行枠** に項目を割り当てます。
- **Chromeのキー設定を開く** から、各「Ribbon 直接実行 1〜30」にキーを設定します。初期状態の直接実行キーは未設定です。
- 登録したキーワードは検索用の短縮名です。キーワードで検索してEnterで実行します。

ChromeやOSの予約キーは利用できないことがあります。キーの変更後は設定画面を再読み込みすると最新の割り当てを表示します。

### ブックマークレット

1. 設定 → **データ・権限** → **① サイトへのアクセスを許可** を選び、Chromeの許可ダイアログで承認します。
2. **② 拡張機能の詳細を開く** を選び、**ユーザー スクリプトを許可する** をオンにします。
3. 拡張画面に戻り **状態を再確認** を押します。反映しない場合は画面を開き直してください。
4. 「追加する」→「ブックマークレット」で、JavaScriptまたは `javascript:` から始まるブックマークレットを登録します。

検索ポップアップでは呼び出した時点のタブ、直接ショートカットではアクティブタブを対象にします。管理画面から実行する際は「アクションの実行先」を明示的に選択します。

自動実行は行いません。Chrome内部ページ、ウェブストア、PDFビューア等には実行できない場合があります。ページのCSP、外部スクリプト、サイト側の構造変更によって動かないコードもあります。

コードはMAIN worldの最上位フレーム内で関数として実行します。ページのDOMや `window` へアクセスできますが、トップレベルの `var` / 関数宣言はページ全体のグローバル変数にはなりません。必要なら `window.xxx` を明示してください。最後の式のPromiseは待機し、同期例外と待機した非同期例外を表示します。タイマー等、実行終了後に発生する例外はブラウザの開発者ツールで確認してください。

## バックアップと保存

- 設定 → データ・権限でJSONをエクスポート／インポートできます。
- インポート時は形式・参照関係を検証し、件数を表示します。確認後に全体を置き換えます。マージ機能はありません。
- 不正なJSONや未対応バージョンは既存データを変更せず拒否します。読み込み上限は10MBです。
- 複数画面から同時編集した場合は、古い内容による上書きを拒否し、最新データを読み直します。
- 保存先はこのChromeプロファイルの `chrome.storage.local` です。同期、クラウド保存、解析通信はありません。プレビューのWeb版は独立した `localStorage` を使用します。
- `tabs` 権限は実行先タブのタイトル・URL表示に使用します。標準ブックマークと履歴APIの権限は取得していません（Chromeはtabs権限を「閲覧履歴の読み取り」と表示します）。

## 開発

Node.js 20.19以降を推奨します。

```sh
npm ci
npm run dev
npm run build
npm test
```

- `src/main.tsx`：ダッシュボード、ポップアップ、編集・設定画面
- `src/model.ts` / `src/storage.ts`：データモデル、検証、保存
- `src/background.ts` / `src/script.ts`：実行要求、ショートカット、スクリプトの構文解析・結果取得
- `public/manifest.json`：MV3設定と30個の直接実行コマンド
- `public/icons/`：添付画像を元に視認性を改善したアイコン、16/32/48/128px

`npm run dev` はUIプレビューです。スクリプト実行・Chromeのキー設定はビルドを拡張として読み込んで確認してください。

## 検証

`npm test` はデータ検証、削除時の参照解除、検索、並べ替え、バックアップ、JavaScript構文と同期・非同期例外を確認します。

UI自動テストは開発サーバー起動中に実行します。

```sh
npx playwright install chromium
node tests/ui.mjs
node tests/features.mjs
node tests/extension.mjs
```

ブラウザのパスを `CHROME_PATH` 環境変数で指定できます。未指定時はPlaywrightのChromiumを使用します。拡張テストには拡張読み込みをサポートするChromiumが必要です。

検証結果と手動確認の範囲は `VERIFICATION.md` を参照してください。
